# Agent contract

Read PROJECT.md and the current AOS rules before work. This repository is **public**:
never copy private requirements, research, user data, backend code, credentials or
discussion from the private control repository into files, Issues or PRs here.

Work from `aos:task` Issues in this repository, one task per run, in a branch, via PR.
Stack: Flutter (team default). Always use the latest stable Flutter/Dart and package versions
(no pre-releases), pin exact versions in pubspec.lock, and upgrade regularly.

Qualify cross-repository references with the full repository name. Do not commit
unlicensed audio or text. Commit messages and user-facing docs in Chinese; code and
identifiers in English.
